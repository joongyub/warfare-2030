▶ 게임 흐름
  서울 강남의 직각 지그재그 도로로 부카니스탄 기갑 행렬이 밀려옵니다. 20웨이브를 막으면 승리.
  · 로비에서 지휘관 이름 저장, 게임 화면 위에 내 프로필 바(이름·보급창)
  · 상점: 보급 충전 ₩3,000 / 7,000 / 10,000 / 20,000 / 30,000 (지금은 테스트 모드, 실제 결제 없음)
    충전한 보급은 '보급창'에 쌓이고, 전투 중 상점에서 +300 / +1,000 씩 꺼내 쓸 수 있음
  · 9번 무기 현무-3: 초장거리 강력 미사일
  · 전략 무기: Z = ICBM(웨이브 5마다 재보급), X = 전략핵미사일(웨이브 10마다 재보급)
  · 드론·헬기는 지상군과 같은 입구로 들어옴 (후반 스테이지는 동서남북 사방에서)
  · 무기 강화 1~4단계: 단계마다 DPS(초당 피해)와 사거리가 함께 오릅니다
  · 효과음·배경 음악 (⚙ 설정에서 끄기, data/settings.js 에서 크기 조절)
  · 3D 원근 시점(각도 하나 고정). 휠로 확대해도 각도는 그대로입니다
  · 전투 구역이 화면을 꽉 채웁니다. 도로와 랜드마크 건물(숭례문·경복궁·N서울타워 등)만 빼고 어디든 무기를 놓을 수 있습니다
    커서 옆에 "자유 배치 가능 / 도로 배치 불가"가 뜹니다
  · 도로 사이에 놓으면 위아래 도로를 동시에 공격합니다
  · [작전 개시]로 첫 웨이브 시작 → 이후 웨이브는 자동으로 이어짐
    [다음 웨이브 ≫]로 앞당기면 남은 초 × 3 만큼 보급 보너스
  · 2.5초 안에 연속으로 10대 이상 처치하면 "연쇄 격파" 보너스
  · 드론·헬기는 한강 위에서 나타나 공원 위를 지그재그로 날아옵니다 (대공 무기 필요)

▶ 폴더 구조
  index.html   게임을 여는 파일
  data/        숫자 데이터 (무기·적·작전 카드·스테이지 도로와 웨이브) ← 메모장으로 고쳐도 됨
  src/         게임 코드 원본 (city.js 도시 풍경, game.js 전투 규칙, ui.js 화면)
  dist/        src를 하나로 묶은 파일 (index.html이 이것을 씀)
  package.json 코드 묶기 설정 (Claude가 사용)
